# ZCode 容器模板

模板固定版本：**3.15.1**。构建来源、下载地址与校验值以本目录 Dockerfile 和部署脚本为准，不代表上游最新版本。

## 使用

先审阅 `compose.yaml`、Dockerfile 与 `deploy.sh`，按自己的目录、网络和基础镜像修改本地配置。`deploy.sh` 会实际安装或启动服务，不能作为只读检查执行。

`data/zcode/` 保存账号与会话，`workspace/` 保存项目。网页/API 需要访问令牌；`.env` 中的令牌和带令牌的链接不应公开。

构建依赖模板中指定的本地基础镜像与上游锁文件；先检查 Dockerfile、镜像及网络条件，不能直接假定新机器已具备这些环境。

通用网络与备份要求见[服务器说明](../../README.md)。修改源码和安装依赖遵循[总项目说明](../../../README.md)。
