# 校园网访问配置说明

本目录只保留通用说明。设备地址、WAN 租约、端口映射、路由脚本和验证记录在所有者本地保存。

配置前确认校园网、主路由 LAN、容器网桥网段是否重叠。若存在回复路由冲突，应按实际网段、下一跳和网卡生成私有配置，并先验证路由选择；不要直接复用其他环境的地址。

端口转发需逐项记录协议、入口端口、目标地址和用途，按实际需要开放。外部可达性应由独立校园终端验证；局域网 NAT 回环测试不能证明跨 VLAN 可达。

通用参数格式见 `../../../automation/parameters.example.json`，计划生成器只生成本地材料。实际持久化路由、端口映射和访问清单不要提交到仓库。
