# Antigravity CLI 容器模板

模板固定版本：**1.3.5**。构建来源、下载地址与校验值以本目录 Dockerfile 和部署脚本为准，不代表上游最新版本。

## 使用

先审阅 `compose.yaml`、Dockerfile 与 `deploy.sh`，按自己的目录、网络和基础镜像修改本地配置。`deploy.sh` 会实际安装或启动服务，不能作为只读检查执行。

配置与缓存分别保存在 `data/` 的对应子目录，项目挂载到 `/workspace`。账号登录需在自己的环境完成。

网络和代理示例需先调整；不要把其他容器的登录信息当作模板分发。

通用网络与备份要求见[服务器说明](../../README.md)。修改源码、安装依赖和归档资料遵循[总维护 Prompt](../../../PROMPT.md)。
