# OpenClash 通用配置说明

本目录不保存实际代理出口、源地址规则、DNS 覆写、节点列表或生效配置。原环境的覆写脚本、验证与回退记录已在本地归档。

配置流程：在本地填写所需容器、地址和代理参数，备份当前路由器配置，生成候选规则并完成语法检查，再按实际需求应用。验证容器出口、DNS、未纳入规则的设备以及故障切换行为。

通用参数和规则生成逻辑见 `../../../automation/parameters.example.json` 与 `../../../automation/prepare_plan.py`。生成器只准备本地材料，不会修改路由器。私有订阅、节点认证及生成的配置应单独保存。
