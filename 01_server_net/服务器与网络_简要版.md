# J1900 服务器与网络搭建记录
简要版  可用于个人博客

我用 Debian 管理 Docker，用 OpenWrt 旁路由处理 DNS、代理和 FRP。先把 OpenWrt 从 U 盘迁到 SSD，确认 SSH、网关和地址，再为容器分配 .101–.107 固定 IP。主路由缩小 DHCP 范围，避免和容器冲突。

部署流程是系统与 SSH → Docker macvlan → 独立应用容器 → OpenClash → 美国中转与 ISP 出口 → 校园转发 → FRP、域名和 HTTPS。

主要困难是大小磁盘迁移、IP 冲突、macvlan 宿主机隔离、校园网段与 Docker 重叠，以及 ISP 拒绝大陆直连。分别用文件级迁移、地址池规划、内部桥接、精确回程路由和 dialer-proxy 解决。DNS 另修正环路与错误解析，最后从容器内部验证出口和服务。
