# 个人博客 Blog 项目记录
简要版  可用于个人博客

我用原生前端和 Node.js 做了手帐风博客，包含生活、学习工作、个人资料和留言，后台可管理文章、心情、阅读计划与配图。内容存 JSON，图片与密码记录独立保存，更新代码保留已有内容。

流程是栏目与页面 → 发布和登录 → 搜索、日历与裁剪 → 字体和动画 → 独立 Docker → FRP、域名与 HTTPS。

主要困难是中文分块乱码、快速导航冲突和内容持久化。分别采用 Buffer 统一解码、取消旧动画、本地字体及串行原子写入。博客最终独立运行在 .101:3000；后台为 /admin。Windows 复查只有 Unix 权限断言失败，发布前需在 Linux 再验收。


## 友链随机排序与本站资料更新 2026年10月19日
