# 可选访客分流说明

这里保留通用设计约束，不保存生产路由映射、出口地址、校园网入口或整套已部署博客副本。正式源码默认不包含原部署快照中的分流集成。

若新环境需要分流，应另行实现与验证；不要假定复制模板即可恢复旧环境行为。候选规则应明确请求来源信任边界、适用路径、重定向目标和回退入口，避免重定向循环及影响后台/API。

`update-china-cidrs.py` 是独立的公开 APNIC 地址数据下载工具，不含部署地址。使用时以 `--output` 指定已有目录中的本地输出文件；该文件不属于仓库正式源码，也不会自动启用分流。

测试应覆盖各类来源、路径、查询参数、不可达目标、HTTPS 和禁用/回退。实际配置、部署记录和访问地址由本地单独保存。
