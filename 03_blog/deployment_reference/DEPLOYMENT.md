# 博客通用部署说明

本仓库只维护 `../source` 一份完整博客源码。原完整部署快照、具体网络 Compose、旧运行时镜像构建材料和迁移脚本已转为本地归档。

新环境使用 `../deployment/Dockerfile.portable`、`../deployment/compose.portable.yaml` 和 `.env.example`。先阅读模板，按自己的网络、目录、镜像和管理员配置修改本地副本；示例值不代表可直接部署的生产设置。

部署前备份数据库、认证配置和上传文件。源码与持久化目录分开存放，核对容器用户写权限及只读挂载。上线后检查首页、后台、API、资源、登录与重启恢复；本说明不宣称已在新环境完成这些验证。

实际部署配置、运行数据、认证信息和访问清单不进入仓库。可选访客分流的设计约束见 [访问自动分流](访问自动分流.md)。
