请作为全栈开发者，直接实现一个可在本地运行并可部署的中文个人博客，风格类似温柔的个人手帐。请完成代码、测试和运行说明，不要只给设计方案。合理的小细节自行决定；缺少素材时先使用明确可替换的本地占位资源，不要留下无反馈的按钮。

一、网站定位与视觉
默认站名“我的记事簿”，站长名称“土豆”，允许集中修改。采用奶油纸张、粉红、柔红和淡紫色，整体清爽，保留留白和清晰的中文层级。首页、生活、学习工作、关于我、留言各有一幅印象派风格背景；可参考睡莲、花田、建筑立面、花园拱桥、日出水面的构图，但使用原创或合法可用素材。装饰人物使用原创角色或可替换的占位插图。文字不能被装饰遮挡，避免每个区域都做成大圆角卡片。手机与电脑均可阅读和操作。

二、页面与功能
1. 首页：站长介绍、四个栏目目录、最近文章、今日心情、最近七条心情、全站搜索。“今日的天气”是心情模块，不调用真实天气接口。
2. 生活日记：文章标题、正文、标签、日期、配图；按年月归档，支持查看和定位指定文章。
3. 学习与工作：学习和工作分区；当天记录直接展示，历史记录用月历检索；阅读计划含书名、作者、目标、0至100进度和随记，完成后自动归档且不重复，换书保留历史和日志。
4. 关于我：头像、姓名、简介、家乡、生日、爱好及介绍、工作经历、分阶段教育经历和可配置的联系方式；支持安全的外链。提供每日轮换的古典寄语，附解释和出处，不编造引文。
5. 留言角：访客可发布话题和回复；话题以气泡显示，打开弹窗后可在阅读和书写之间切换。按话题保存会话内草稿，切换时不丢输入；明确提交中、成功及失败反馈。
6. 独立 /admin：公开页面不展示管理员入口。登录后管理文章、资料、心情、阅读计划和留言，并能修改密码。所有写权限都在服务端校验。

三、技术与数据
采用原生 HTML、CSS、JavaScript 和 Node.js 20+ ES Modules，服务端优先使用内置模块，避免无必要的构建步骤与运行依赖。提供 npm start、npm run dev、npm test。公开页与后台复用前端逻辑，hash 路由可携带内容 ID，支持搜索深链接定位。
内容持久化到 data/blog.json；首次启动写入演示数据，后续更新代码不能覆盖已有数据；新增字段兼容旧数据。保存采用串行队列、临时文件加原子替换。上传图片保存到 public/assets/uploads/。文档明确备份数据、上传资源和密码记录，说明此文件存储方案的单实例使用范围。

四、图片与字体
文章支持最多9张PNG、JPEG或WebP，每张不超过2MB；头像支持同样格式。用本地打包的Cropper.js提供裁剪、缩放、旋转、重置和保留原图；文章裁剪支持正方形、4:3、3:4和自由比例，头像方形，输出最长边不超过1600像素。上传前可预览和重新裁剪，服务端验证格式、大小、文件标识和图片路径。说明移除引用与清理磁盘文件的区别。
使用本地中文可变WOFF2字体，统一正文与标题字体栈；保留unicode-range按需加载，每个Latin或补充字符子集都必须对应正确文件，不误用同一文件覆盖多个范围。保留第三方许可证，运行时不依赖外部字体、图片或脚本CDN。

五、交互要求
首页四个目录入口使用纸张翻页；公开内页使用一致的模糊切换，扇形导航支持预览与选择。同页锚点不触发整页转场。快速连续导航只提交最新目的地，取消旧动画并清理遮罩；异常时也能恢复。局部内容变化从当前可见高度过渡。支持键盘、焦点管理、触屏与prefers-reduced-motion，减少动态效果时直接完成操作。
首页搜索全站，内页只搜索本栏目，结果能展开并滚动到目标内容；内页搜索放在主体内容下方。

六、服务端要求
初始密码通过BLOG_ADMIN_PASSWORD注入；可提供.env读取，但须明确哪些变量由程序加载。登录使用随机会话令牌和HttpOnly、SameSite Cookie；HTTPS可启用Secure。改密校验当前密码和两次新密码，新密码8至200字符，以随机盐加scrypt哈希保存，文件权限600，改密后撤销全部会话。限制请求频率、请求体大小与字段长度；校验日期和链接，转义不可信文本。
请求体先累积Buffer并统计字节，最后统一UTF-8解码再解析JSON，避免中文与表情被网络分块截断。静态文件访问应防止目录穿越，只暴露允许公开的资源。

七、验证与交付
使用node:test编写有意义的回归测试，覆盖访客越权、登录与改密、重启持久化、图片限制、阅读档案去重、搜索范围、留言草稿、跨字节UTF-8请求以及动画快速切换和减少动态效果。运行测试并报告真实结果；实际检查桌面和手机尺寸布局，修复横向溢出、遮挡与缺字。
交付完整代码、可编辑示例内容、文件结构说明、启动命令和README。README附Ubuntu部署示例：systemd管理进程、Nginx代理、HTTPS、环境变量、目录权限和备份恢复。执行需要额外授权的外部发布前，先完成可本地审查的结果并列出部署步骤。不要把尚未执行的部署或测试写成已完成。
