# 博客友链与图片显示更新日志

日期：2026-10-18，Asia/Shanghai。

新增独立友链花园页面（/#friends，也可直接访问 /friends），首页使用花朵邀请卡片，并在页头提供快捷入口。访客可提交站点名称、完整网址、简介和可选头像，申请先进入待审核；管理员在 /admin#friends 可直接提交发布，也可审核、编辑、下架和删除。

配图改为优先完整显示：单图保留原比例，高度最多为视口的 75%；多图使用两列画框并以 contain 完整缩放，预览与首页画作也避免强制裁切。横图、竖图和混合图片已在桌面与 390 像素手机布局检查，点击配图仍可打开原图。

友链保存于 data/blog.json 的 friends 数组，旧数据启动时兼容补空数组。GET /api/friends 只公开已发布条目；管理员 GET /api/friends?review=1 查看全部；POST /api/friends 提交；PUT 与 DELETE /api/friends/:id 均由服务器验证管理员会话。访客不能通过伪造 status 越过审核。

站点及头像仅允许完整 http 或 https 网址，拒绝脚本协议、内嵌账号密码和过长输入；保存前检查重复网址，文字输出转义。服务器不主动抓取申请站点；公开链接在新窗口打开并设置安全 rel，远程头像失败时回退为站名首字。

修改 JavaScript 后已运行 npm test。Windows 仍只有原有的 Unix 0600 权限断言失败；在 Debian 的 Node.js 24.22.0 隔离容器内，较新源码 35/35、带访问分流的部署版 39/39 全部通过。新增测试覆盖申请隐藏、管理员提交与审核、网址校验、重复提交、编辑下架删除和重启持久化。没有新增依赖。

独立 web 容器已更新并重启验收，局域网 /friends 和 /api/friends 返回 200。上线前备份 app、data、uploads、环境与 Compose 配置，备份保存在 /srv/web/backups/blog-friends-20261018-091348.tar.gz，权限 600。文章与资料、上传图片、密码记录及 routing.json 校验一致，校园 DDNS 与既有 FRP 分流继续保留。

回退时先保留当前 data 和 uploads，再从本次备份恢复 app 并重启 web。旧版本会忽略 friends 字段；不要为回退覆盖新写入的文章或删除数据卷。备份包含私有环境文件，只留在服务器的受限目录。
