# 证据与时间顺序

`snapshot.json` 固定本次采用的源码版本和最新地址。`conversation_inventory.json` 列29份本地会话文件（28个会话ID）；一个会话分成迁移前后两段。`original_file_inventory.json` 为原515个文件的路径、长度与SHA256，仅列清单，不带文件正文或凭据。

`项目网络配置报告.md` 是原审计资料，含后续补记和旧段落，不能把每一段当成同一时刻的最终状态。

博客部署副本的routing.json仍是旧campusTarget。文档说明更正值并不代表修改了生产服务器；本次没有执行线上配置更新。以后部署先读取当前值和WAN，再决定变更。

原始会话、工具输出、生产凭据和数据保留在原机器，没有装入Git仓库。历史验证与本次测试分开，见`validation.json`。原Word来源是教程素材，里面的命令没有被当作本次部署授权。
